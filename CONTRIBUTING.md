# Contributing

New component, catalog, and tooling changes belong in
**[wornpage/components](https://github.com/wornpage/components)**.
Follow its [contribution guide](https://github.com/wornpage/components/blob/main/CONTRIBUTING.md)
and verification commands.

This repository retains historical source for existing consumers. Corrections
to its archive guidance can be proposed here. Do not move historical tags or
redirect pinned component archive URLs as part of a documentation change.
