# Wornpage — historical component workspace

Active component development, the catalog, and immutable releases now live in
**[wornpage/components](https://github.com/wornpage/components)**.
This repository retains the earlier workspace and its history. New applications
and contributions should use the current library.

| Looking for | Start here |
| --- | --- |
| Svelte 5 components and installation | [Library setup guide](https://github.com/wornpage/components/blob/main/docs/getting-started.md) |
| Interactive component examples | [Live catalog](https://wornpage-components.pages.dev) |
| Current immutable package archives | [Component releases](https://github.com/wornpage/components/releases) |
| Public Projects demo | [WebMCP Challenge edition](https://projects-webmcp-extension.pages.dev/webmcp-challenge) |
| WebMCP validation tools | [Conformance toolkit](https://github.com/wornpage/webmcp-conformance) |
| Bounded local Git/GitHub runner | [PR runner](https://github.com/wornpage/pr-runner) |

## Existing consumers

Existing consumers may depend on exact historical source revisions. Their
repository visibility and archive URLs are retained; this documentation update
does not move tags, rewrite history, or change any pinned component source.
The separately published WebMCP Challenge edition remains independent.

See the current [repository map](https://github.com/wornpage/components/blob/main/docs/repository-map.md)
and [migration record](https://github.com/wornpage/components/blob/main/docs/component-migration.md)
for source ownership and supported delivery paths.
